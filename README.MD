# NesDQ

ファミコン版RPGをWindows／Androidで快適に遊ぶアプリです。DQ4・DQ3・FF2・FF3の倍速プレイに対応しています。ROMは同梱しません。

正式版 **1.0.2**。Windows 10／11のx64版、Android 6.0以降のarm64端末向けです。

## インストール

- Windows：配布フォルダーの `nesdq.exe` を起動します。インストール作業や追加DLLの配置は不要です。`Rom` フォルダーにROMを置くこともできます。
- Android：`NesDQ-1.0.2-android-arm64.apk` を端末で開いてインストールします。初回起動時に、ROM・保存データを置くフォルダーを選択してください。

以前のデバッグ版Androidアプリとは署名が異なるため、そのまま上書きできません。選択済みの外部 `NesDQ` フォルダー内の `Save`・`state` と設定ファイルを残し、旧版をアンインストールしてから正式版を入れ、同じ外部フォルダーを選び直してください。アプリ専用の内部保存先にデータが残っている場合は、削除前に外部フォルダーへの移行を済ませてください。

## 起動

Windowsは起動時のファイル選択でROMを選びます。初回の選択先は実行ファイルの隣の `Rom` フォルダーで、以後は前回の場所を記憶します。ROMパスを起動引数で指定することもできます。

Androidは初回にDocumentsを選ぶと、その中に `NesDQ/Rom`・`Save`・`state` を作成します。既存のNesDQフォルダーも選べます。その後、起動時にROMを選んでください。タッチ操作は縦画面・横画面に対応します。

起動後は機能メニューの **Select ROM** から別のゲームへ切り替えられます。WindowsはOキー、Androidは画面上のROMボタンからも選べます。切替前に通常セーブを保存し、選択をキャンセルした場合や読込に失敗した場合は現在のゲームを保持します。速度設定と保存データはROMごとに引き継ぎます。

## 操作

- 方向キー：移動。X／Enter：A。Z／Backspace：B。A／Tab：Select。S／Space：Start。
- Q／Esc／左スティック押し込み：メニュー。上下で選択、Enter／Xで決定、Z／Backspaceで戻る。
- F1〜F5：各スロットへ保存。Shift＋F1〜F5：読込。LT／ZL：スロット1保存。
- メニューのSpeedを選び、左右で速度を変更。F6でも1→2→3→4→5→6→1倍へ変更できます。
- メニューのSwap A/B：ゲーム中のA/Bを入れ替え。キーボード・ゲームパッド・タッチ操作に共通で適用し、次回起動時も記憶します。メニューの決定・戻る操作は共通です。
- DQ3・DQ4・FF3は、メニューのBattle EXP／Battle Goldを左右で変更すると、戦闘の獲得経験値／ゴールドをそれぞれ1・4・8・16・64・128倍にできます。設定はROMごとに記憶します。FF2の報酬倍率はBattle Goldのみ対応します。
- FF2のMax Wpn/MagicをOnにすると、戦闘勝利後に4人分の全武器と習得済み魔法がLv16になります。FF3のMax Job skillは、4人分の現在のジョブ熟練度を99にします。左右または決定で切替でき、初期値はOff、設定はROMごとに記憶します。最大化した値はOffにしても戻りません。
- FF3のFree JobsをOnにすると、キャパシティ0でもジョブチェンジでき、キャパシティも消費しません。レベル・装備解除・ジョブ解放の条件は原作どおりです。左右または決定で切替でき、初期値はOff、ROMごとに記憶します。必要キャパシティの表示は原作の値のままです。
- ゲームパッドの右側フェイスボタン：NES A。下側：NES B。Back／Start：Select／Start。

戦闘報酬の倍率は、経験値の人数分配後に適用します。宝箱・売却・イベント報酬は対象外です。桁あふれ防止のため、1回の獲得上限はDQ3・FF3の経験値が1人65,535、DQ4の経験値が6,777,216、ゴールドは4作品とも65,535です。ステート読込後も現在の倍率設定を使います。

確認済みROMでは1〜6倍を選べます。DQ4・DQ3のBGM・SE、FF2・FF3のBGMと主要SEは倍速でも等速で再生します。FFの一部の専用イベント音は未対応です。4作品ともメニューの方向キー長押し間隔を補正します。初期速度は1倍で、選んだ速度をROMごとに記憶します。未対応のROMは1倍速で動作します。

## 保存

通常セーブは10秒ごと、フォーカス喪失・バックグラウンド移行時、正常終了時に保存します。Androidの定期保存はバックグラウンドで書き込み、終了・バックグラウンド移行時には完了を待ちます。Windowsの保存先は `%APPDATA%/NesDQ`、Androidは選択したNesDQフォルダーです。通常セーブは `Save/ROM名.sav`（例：`game.nes` → `Save/game.sav`）、5枠のステートは `state` に保存します。旧版のハッシュ名セーブは初回読込時に自動で引き継ぎます。ROM名のセーブが既にある場合はそちらを優先します。

新しいステートには倍速の設定と音声の状態も含まれます。旧形式のステートは読み込めますが、等速音声のBGMは再開時に先頭からになります。新形式は旧版のアプリでは読み込めません。

## 対応範囲

対応対象はDQ4・DQ3・FF2・FF3の4作品です。DQ1・DQ2は対象外です。利用するデータによってはSpeedなどの追加機能が利用できない場合があります。ゲーム全場面の操作、Android実機の6倍速性能、OS間のステート互換性は未確認です。

ROMの元ファイルは変更しません。binjnes（MIT）、SDL3（zlib）、PicoSHA2（MIT）を使用しています。配布物の `licenses` を参照してください。
